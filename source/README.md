# NEON//SURVIVORS 2199

Вертикальный кибер-рогалик на выживание под один палец: забег 5 минут на одной из трёх планет и бесконечный режим после финального босса. 7 пилотов с уникальными перками, 14 видов оружия с эволюциями (4 слота в забеге), перки-правила, модули корабля, монетизация только рекламой (пока заглушки).

Принципы проекта — 10 столпов вижна, см. [docs/HISTORY.md](docs/HISTORY.md), п. 17.

Играть: https://korolevasofia0408-arch.github.io/neon-survivors/

```bash
npm ci
npm run dev     # разработка, http://localhost:5173
npm run build   # dist/index.html — вся игра в одном файле
```
