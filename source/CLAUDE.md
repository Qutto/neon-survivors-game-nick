# NEON//SURVIVORS 2199 — контекст проекта для Claude

Браузерный рогалик на выживание в духе Vampire Survivors, киберпанк-сеттинг, весь интерфейс на русском.
Игрок выбирает пилота и планету, корабль стреляет сам, игрок только двигается и выбирает улучшения при повышении уровня.

**Вижн (10 столпов, HISTORY.md п. 17) — фильтр для любой новой фичи:** играется одним пальцем, работает в вертикали, добавляет решение на экране выбора (а не рефлекс), укладывается в забег 5–6 минут, монетизация только рекламой, переживёт смену визуала.

- Живая версия: https://korolevasofia0408-arch.github.io/neon-survivors/ (GitHub Pages, публичный репозиторий `neon-survivors`, в нём лежит только собранный `index.html`).
- История разработки и все решения владельца: [docs/HISTORY.md](docs/HISTORY.md). Прочитай перед крупными изменениями, особенно раздел «Решения, которые уже приняты».

## Стек и команды

React 19 + TypeScript 5.9 + Vite 7 + Tailwind 4. Игра рисуется на `<canvas>` собственным движком, без игровых библиотек.
`vite-plugin-singlefile` собирает всё (JS, CSS, картинки в base64) в один `dist/index.html` (~2.8 МБ). Звук синтезируется кодом, аудиофайлов нет.

```bash
npm ci                 # зависимости
npm run dev            # http://localhost:5173
npx tsc --noEmit -p .  # проверка типов (strict, noUnusedLocals) — должна быть чистой
npm run build          # dist/index.html — один файл, открывается даже двойным кликом
```

## Как устроены ключевые системы

- **Данные отдельно от движка.** Волны, события, враги, планеты и модули — это таблицы. Новая планета или враг почти всегда добавляются правкой `planets.ts`/`data.ts`, без изменений движка. Враг может переиспользовать чужой рисунок через поле `sprite`.
- **Планеты (забег 5 минут):** `home` (Нео-Терра, испытание для новичка, купол в центре понемногу чинит, финал «Осадный дредноут»), `ice` (Крио-7, инерция `traction`, метели `blizzard`, финал ОМЕГА-ЯДРО), `hive` (Улей Ксенос, гнёзда `nest`, деление врагов `split`, элитка каждые 25 с, финал «Праматерь Ксенос»). Босс-середина в 02:30, финал в 05:00, у события босса может быть `hpMul`. Рост врагов и волны идут по «времени планеты» `planetTime(t, timeScale)` — плавный разгон к финалу до 05:00 × timeScale (1.5 / 1.6 / 1.7). Первые 2 минуты магнит падает по расписанию `MAGNET_SCHEDULE`. Следующая планета открывается победой на предыдущей. Победа — убийство `finalBoss`.
- **Бесконечный режим — испытание, не ферма (HISTORY п. 18):** после финального босса движок ставит `modal = "victory"` и зовёт `onVictoryChoice`; `chooseEndless(true)` — всплеск врагов и ступени угрозы каждые `ENDLESS_STEP` с (старт с `ENDLESS_START_LEVEL`): здоровье/урон новых врагов ×`ENDLESS_HP_STEP`/`ENDLESS_DMG_STEP` за ступень, плотность +`ENDLESS_SPAWN_STEP`, босс раз в `ENDLESS_BOSS_EVERY`, награды +`ENDLESS_REWARD_STEP` за ступень. Смерть в бесконечном режиме = победа.
- **Протокол:** перки-правила не выпадают картами — после первого убитого босса `openProtocol()` даёт выбор 1 из 3 (`onProtocol` → `chooseProtocol`), один на забег.
- **Броня** вычитается из удара, но не больше 75% (`ARMOR_FLOOR`).
- **Билд:** 4 слота оружия (`MAX_WEAPONS`), пассивки по модели `settings.passiveModel` (A — 4, B — без лимита; `maxPassives`). Карта `kind: "wmod"` — мод оружия для пушки на пределе (до `MAX_WEAPON_MODS`). Перки-правила (`RULE_PERKS`) приходят только через протокол; эффекты — в `eff()`, `recomputeStats()`, `damageEnemy()` (ищи `this.has("…")`).
- **Пилоты (контент коллеги, HISTORY п. 19):** родная пушка получает `sig` в `eff()`. Когда она эволюционировала, следующий контейнер даёт **пробуждение** (`awakened`, `isAwakened(w)`): эффект живёт в функции пушки или в `updateAwaken`. Пилоты с `unlock` открываются достижениями (`autoUnlock` в `save.ts`, счётчики `bossKills/eliteKills/bestBaseStay`).
- **Броня элиток и боссов:** `Enemy.armor` (`ELITE_ARMOR/BOSS_ARMOR` от времени планеты) вычитается в `damageEnemy`, удар не слабее `ARMOR_MIN_HIT`; пробивают `armorPen`, мод «Бронебойный», заморозка «Абсолютного нуля».
- **Классы врагов (HISTORY п. 20):** `ENEMY_CLASSES` — `fast`/`mid`/`heavy` (скорость — доля от скорости пилота, ХП — в эталонных попаданиях `ENEMY_REF_HIT`), враги задаются через `mob(id, имя, класс, множители)`. Элитки — отдельный слой `ELITE` (свои ХП/урон/скорость, рывок с замахом `updateEliteLunge`, облик — `pickEliteBase`). Проверка — `tools/sim/measure.ts` (время до смерти по классам).
- **Угрозы без буллет-хелла:** пуль мало и они медленные (`BULLET_*`, `GUNNER_FIRE_EVERY`); основная угроза боссов — войд-зоны (`castVoid`/`voidsAroundPlayer`/`updateVoids`), «Пустотные» элитки (`voidy`) оставляют маленькие.
- **Один палец:** активных кнопок в бою нет. Рывок удалён, модуль «Отталкиватель» (`mod_repulsor`) срабатывает сам. Условные бонусы «стоя» (`stillT`) — отпустить палец тоже действие.
- **Вертикаль:** брейкпоинты Tailwind выключены в `index.css`, на ПК всё в `.phone-frame` (9:16). Не используй `sm:/md:/lg:` — они не сработают.
- **Сила боссов** = `def.hp × planet.bossHpMul` и не зависит от уровня игрока. Это намеренно: раньше она росла с уровнем, и на 125-м уровне у ОМЕГИ было 150 тыс. здоровья.
- **Арена:** `inArena/clampToArena/clampPoint/randomArenaPoint`. Игрок и враги не выходят за забор, спавн подбирается внутри арены. Квадратная арена есть только у Улья: углы — ловушка, и для самой сложной планеты это уместно.
- **Модули:** в движок приходят `cfg.modules` (установленные, id → уровень) и `cfg.owned` (коллекция, нужна для дубликатов). Пассивные бонусы модулей добавляются в `computeStartStats`, активные (отталкиватель, щит, импульс, сборщик, хроноядро, сканер) — в `updateModules`/`hurtPlayer`. Переименованный модуль — добавь в `MODULE_RENAMES`, сохранения перенесутся.
- **Реклама (заглушка, точки коллеги):** воскрешение (`onReviveOffer` → `acceptRevive/declineRevive`, окно на 9 с), переброс ×3 за забег (`adReroll`, когда обычные кончились), «открыть контейнер ещё раз» ×2 (`chestAgain`), ×2 к ежедневному контейнеру (`claimDaily`), ×2 кредита на итогах. Межстраничной рекламы и контейнера в ангаре нет — это решение владельца.
- **Экономика:** кредиты (все планеты, множитель `rewardMul`) и фрагменты (только Крио-7 и Улей, плюс разбор дубликатов модулей). Лаборатория после максимума уходит в бесконечную «перегрузку» (`OVERLOAD_FACTOR = 0.5`, цена ×1.22 за уровень; перебросы, доп. снаряд и воскрешение исключены). В забеге после полной прокачки предлагаются бесконечные сверхулучшения.
- **Баланс поздней игры:** все рычаги — константы в `data.ts` (раздел «Баланс поздней игры»): скорость досыпания спавна, мягкий потолок площади, убывание сверхулучшений, рост опыта после 30-го уровня, щит босса при входе. `planet.xpMul` — множитель опыта планеты. Подробности и замеры — HISTORY.md, п. 15. Проверять — `tools/sim`.
- **Сохранения (`localStorage`):** `neon-survivors-2199-save` — настоящее, `neon-survivors-2199-sandbox-save` — тестовое, `neon-survivors-2199-sandbox` — флаг тестового режима. Новые поля добавляй в `SaveData` + `DEFAULT_SAVE` + слияние в `loadSave`, чтобы старые сохранения игроков не ломались.
- **Тестовый режим** (Настройки): отдельное сохранение, где всё открыто и есть 999 999 кредитов. В нём доступен «режим бога» (`settings.godMode`, бессмертие). Вне тестового режима `godMode` принудительно сбрасывается в `App.tsx`, чтобы бессмертием нельзя было заработать настоящий прогресс.

## Соглашения

- Тексты интерфейса и комментарии в коде — на русском, в том же тоне (киберпанк, коротко).
- Стиль: Tailwind-классы, неоновые цвета, компоненты из `ui.tsx` (`NeonButton`, `Panel`, `ItemIcon`). Иконки из `lucide-react`; новую иконку модуля или улучшения регистрируй в `ITEM_ICONS`.
- Перед сдачей: `npx tsc --noEmit -p .` без ошибок, `npm run build`, затем автопроверки из `tools/playtest`.
- Проверяй и вид на телефоне (390×844): у игры сенсорное управление (джойстик пальцем, кнопок в бою нет).

## Плейтест-бот (tools/playtest)

```bash
npm run build
cd tools/playtest && npm run setup   # один раз: Playwright + Chromium
npm run check                        # тестовый режим и режим бога
npm run screens                      # скриншоты меню/ангара/лаборатории/планет, ПК + телефон → out/screens
node bot.mjs 400 Кай НЕО-ТЕРРА home fresh    # длительность(с) пилот ПЛАНЕТА метка профиль; ENDLESS=1 AD=1 MODEL=B UNLOCK_ALL=1
node vision-screens.mjs                      # скриншоты систем вижна (телефон + ПК) → out/vision
```

- Бот открывает игру с `?bot` в вертикальном окне 390×844, и тогда движок доступен как `window.__engine`. Бот уворачивается от врагов, пуль, войд-зон и стен, собирает опыт, жжёт гнёзда, выбирает улучшения и перки по приоритету, отвечает на окна победы и воскрешения и раз в 20 с пишет лог.
- Профили сохранения: `fresh` (новичок), `mid` (пофармил Нео-Терру), `high` (прошёл Крио-7). Проверять 2-ю и 3-ю планеты с `fresh` бессмысленно.
- Ограничения бота: он видит врагов сквозь метель, не учитывает занос на льду и плохо уходит от рывков боссов. Его результат — ориентир, а не истина. Флаги `--use-angle=d3d11` рассчитаны на Windows; без видеокарты FPS падает до ~20, и бот играет заметно хуже.

## Headless-симулятор (tools/sim)

```bash
cd tools/sim && npm run sim -- hive ghost 6 1    # планета пилот минуты godMode(1/0)
FRESH=1 npm run sim -- home recruit 6 1          # профиль новичка без меты и модулей
ENDLESS=1 npm run sim -- ice echo 10 1           # после финала — бесконечный режим
PERK=rule_monolith MODEL=B npm run sim -- ice titan 6 1   # брать этот перк, пассивки без лимита
```

Гоняет `Engine` в Node без браузера (canvas и DOM заглушены) с АоЕ-приоритетом выбора улучшений, раз в минуту пишет уровень, убийства, число сверхулучшений, урон, площадь, врагов на поле. Прогон 15 минут — ~15 с. Бот не уворачивается, поэтому смотреть стоит на прогрессию (режим бога), а не на выживание.
